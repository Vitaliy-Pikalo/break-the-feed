# Break the Feed

[Open the interactive replay](https://vitaliy-pikalo.github.io/break-the-feed/)

A C++17 market-data simulator compares two consumers reading the same stream of absolute price-level updates. The exchange starts with bids at 49¢ and 48¢. Drop the message deleting 49¢ and step through the replay to see which consumers keep publishing it.

| Simulated time | Exchange and consumers |
|---|---|
| 100 ms | The exchange deletes 49¢. Both consumers still publish it. |
| 140 ms | Sequence 2 arrives. The guarded consumer detects the gap, suppresses its bid and requests a snapshot. |
| 190 ms | Sequence 3 arrives during recovery and is buffered. |
| 220 ms | The snapshot covering sequence 2 arrives. The consumer installs it, applies sequence 3 and publishes 48¢. |
| 400 ms | The observation ends. The naive consumer still displays 49¢. |

The naive bid is wrong for 300 ms of the observed window. The guarded bid is wrong for 40 ms and unavailable for another 80 ms. Select **Deliver every packet** to run the control. These are simulated event times on a fixed tape. Network performance and throughput are outside this experiment.

## Build and run

Use a C++17 compiler and CMake 3.16 or later. With a single-configuration generator:

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
./build/feed --drop
./build/feed --clean
```

On Windows with a Visual Studio generator, build with `cmake --build build --config Release`, test with `ctest --test-dir build -C Release`, and run `build\Release\feed.exe --drop`.

The CLI emits one CSV row per state transition. A blank guarded bid means publication is paused. The browser reads traces generated by the same executable. To regenerate them, run `python tools/export.py PATH_TO_FEED`. Open `docs/index.html` locally for offline playback.
